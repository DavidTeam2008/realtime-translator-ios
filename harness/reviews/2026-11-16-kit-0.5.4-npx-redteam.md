## 4. 被挑战的假设

- 「0.5.4 distribution-only」被否定：模板内嵌版本 → 宿主渲染文件会变（已改为诚实的小升级）。
- 「一条 npx 命令全宿主可用」被否定：需 `-g` + 双 agent + `-y`。
- 「resolver 自动 clone 让 skill 自足」需限定：内嵌 kit/旧 meta/npx 管理会改变解析路径。
- 「单测覆盖 npx 入口」不成立：单测只覆盖 resolver 逻辑，npx 布局由人工 E2E + 发布清单覆盖。

## 5. 缺失信息与待验证

- npx CLI 未来版本是否改变默认安装布局/锁文件位置（当前以 1.8.1 为验证基线）。
- 网络受限环境（HTTPS 到 github.com 失败）下的默认路径体验；本次本机出现一次 HTTP2 framing/超时，重试成功。
- Windows 未实测；缓存信任边界为 TOFU（发布约定不 force-move 已发布 tag）。
