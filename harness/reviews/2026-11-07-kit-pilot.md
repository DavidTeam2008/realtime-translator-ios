## 4. 对 README / playbook 的具体修正建议

1. playbook §4：把"填命令"改为"确认 init 推断值"（见卡点 1），并明确 `--test-command` 可显式覆盖。
2. playbook §5：在 `make plan` 与证据之间补"填计划必填节 + `git commit`"两个动作，并注明"未完成时 `make check` 会红是预期"（卡点 2/3）。
3. README「10 分钟接入」：把"4) commit scaffold"从 init 输出提升到 README 主流程（证据链的前置条件），避免只读 README 的人先跑到 dirty tree 的坑。
4. （可选）README 明确"首次 `make check` 由 init 自动执行并透传退出码；PASS 后无需重复"— 本次实测确实一次通过，可写进"接入成功判据"作为正向信号。
