# 澄清记录 · add-swipe-back-gesture（2026-11-19）

## 用户需求

- 原话 1：「对译APP增加优化退出功能」。
- 原话 2（澄清后）：「对译APP增加右滑返回上一级页面功能」。

## 现状核查

- 所有页面隐藏系统导航栏，使用 `ModuleChrome` 自定义「首页 / 历史」入口。
- 2026-11-19 在 iPhone 17 Pro Max / iOS 26.4.1 模拟器验证：模块页左边缘右滑不返回上一级。
- 模块页 `onDisappear` 已负责停止听写；首页/切后台/杀进程的任务语义已存在。

## 澄清结论

- 目标行为：任意已推入页面，从屏幕左边缘开始右滑，返回上一级。
- 首页（导航栈为空）不触发；短距离、纵向滑动、非边缘起点不触发。
- 现有「首页 / 历史 / 结束任务 / 新任务」入口与任务语义保持不变。
- 不在本次范围：App 退出、sheet 下滑关闭、跟手交互式转场。

## 方案取舍

- A：重设 UIKit 内部 `interactivePopGestureRecognizer`，原生跟手，但依赖隐藏导航栏的内部视图层级，跨版本脆弱。
- B：根级左边缘 `DragGesture` + 可单测策略，非跟手但稳定、可 UI 自动化验证。
- 决策：采用 B；若后续 UI 测试发现手势竞争，再评估 A 或窄条命中区。
