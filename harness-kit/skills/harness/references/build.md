# 实现 / 修 bug / 重构

1. 读根 `AGENTS.md` 与 active 计划；按路由读 `references/` 或嵌套 `AGENTS.md`；不要凭记忆。
2. 确认本次任务在 scope 内；越界先停下更新计划。
3. 分级：L0 直接做；L1 5–10 行短方案；L2 完整方案 + 用户确认（高风险加独立复核）。
4. 一次一个可验证点；测试先行或同步补测试；不顺手重构无关文件。
5. 完成后跑 `python3 tools/harness.py verify`（同步未提交段 + 门禁 + 计划严格校验 + 证据摘要）；测试类声明先写 evidence（见 `verify.md`）。
6. 门禁失败先定位根因；同一失败修 2 次仍红 → 停，按 `references/workflow.md` 上报。

## 禁止
- 不删/放宽既有断言；不跳过测试变绿；不在未更新计划的情况下扩大范围。
- 不清理未声明的未提交改动；不提交构建产物/日志/本机路径。
