# 评审 / PR 前自检

## 自检（作者）
- 改动是否都在 scope 内；是否有无关格式化/重构混入。
- 新增/变更行为是否有测试；测试是否只增不减。
- 文档/计划/证据是否同步；`harness.py verify` 是否 PASS；未验证项是否单列。
- 安全：无密钥/Token/本机绝对路径/设备 ID 入库；依赖变更有理由与许可证。

## 对抗评审（高风险 L2）
- 开新会话或独立 Agent，输入只有：任务 + 方案 + 仓库路径；不传起草对话与自评。
- 输出：结论、P0/P1/P2 表（问题 | 证据/位置 | 影响 | 建议）、被挑战假设、缺失信息、最小验证清单。
- 作者逐条回应（接受/拒绝/待定 + 理由），最多两轮；P0/P1 执行前解决。
- 评审记录引用被评审 commit / evidence id，写入 `harness/reviews/`。

## PR
- 先问用户再 push/PR；PR 描述附：改动、验证命令与结果、证据 id、未验证项。
