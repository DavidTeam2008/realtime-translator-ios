# 01 产品设计（当前实现）

> 本文描述**当前代码实际提供的产品行为**，不是早期设计稿。
> 交互原型在 [`../prototype/`](../prototype/)，只作为视觉/布局参考；与本文冲突时以代码为准。
> 架构见 [`02-architecture.md`](02-architecture.md)，选型见 [`03-tech-choices.md`](03-tech-choices.md)。

产品名：**对译 Duiyi**
形态：iPhone 原生 App，仅竖屏；iPhone 13 及以上可安装，语音/翻译依赖系统端侧模型。
核心承诺：不联网、不登录、不上传音频；听写、翻译、任务记录都在本机完成。

---

## 1. 三个模块

| 模块 | 谁在用 | 屏幕 | 产出 |
| --- | --- | --- | --- |
| 面对面 | 两人隔桌，手机平放 | 上下对半，上屏旋转 180° | 双方各自在自己朝向的一侧读译文 |
| 同声传译 | 一个人听现场 | 单栏正字 | 实时译文，可选耳机朗读 |
| 会议记录 | 一个人记一场会 | 单栏正字，全文稿 | 完整文字稿 + 会后总结 + 导出 |

三个模块共用：六种现场语言、权限、端侧听写/翻译、任务与历史、总结与导出。
首页用三张大卡片进入模块，历史单独一张卡片；没有账号、云同步、付费墙。

---

## 2. 共享规则

### 2.1 语言

`AppLanguage` 当前支持六种：

| 语言 | 听写 locale | 翻译 locale | TTS voice |
| --- | --- | --- | --- |
| 简体中文 | `zh_CN` | `zh-Hans` | `zh-CN` |
| English | `en_US` | `en` | `en-US` |
| 日本語 | `ja_JP` | `ja` | `ja-JP` |
| 한국어 | `ko_KR` | `ko` | `ko-KR` |
| ไทย | `th_TH` | `th` | `th-TH` |
| Tiếng Việt | `vi_VN` | `vi` | `vi-VN` |

- 界面文案跟随「我看的语言」（`PreferencesStore.userLanguage`），不跟随系统语言。
- 现场语言与界面语言分开：同一台手机可以界面中文、现场英→日。
- 默认对侧语言：英语以外的语言默认对侧英语；英语默认对侧中文（`defaultPeer`）。
- 端侧能力以 `SpeechTranscriber.supportedLocale`、`LanguageAvailability` 和 `AVSpeechSynthesisVoice` 实查为准；不假设六种语言在所有设备都可用。

### 2.2 离线与隐私

- 音频只用于实时听写，不写磁盘；任务只保存文字稿。
- 无后端、无 API Key、无分析 SDK；系统模型下载由 `AssetInventory` / `TranslationSession.prepareTranslation` 管理。
- 不支持后台音频；离开 App、锁屏或进入后台时停止听写，任务保持「进行中」。
- `Info.plist` 只声明麦克风与语音识别权限，不申请相册、通讯录、跟踪。

### 2.3 会话状态

三个模块共用 `SessionState`：

`idle → preparing → ready → listening ↔ paused`，失败进入 `failed(DuiyiError)`。

- **开始/暂停只控制麦克风**，不结束任务；字幕和任务都保留。
- 暂停 30 秒后恢复系统自动锁屏；聆听中保持屏幕常亮。
- 错误只在用户能读懂的一侧显示；倒字侧不显示系统错误。

## 3. 面对面（Conversation）

### 3.1 场景与布局

两人隔桌，手机正面朝上平放在中间。屏幕竖向对半：

- 上半屏：对方阅读，整块容器 `rotationEffect(180°)`，文字仍按正常方向排版。
- 下半屏：用户阅读，正字。
- 中央控制带 72 pt：64 pt 麦克风按钮，88 pt 点按区，骑在分割线上。

锁定竖屏，不靠重力翻转；对方侧不进入 VoiceOver 无障碍树。

### 3.2 语种即路由

单麦克风不做稳定说话人分离，当前实现用**识别语种**决定字幕去哪一侧：

| 识别语种 | 译文去向 | 说话侧提示 |
| --- | --- | --- |
| 用户语言 | 对方屏（上半） | 用户侧显示「正在说…」 |
| 对方语言 | 用户屏（下半） | 对方侧显示「正在说…」 |

- 每侧只保留 `live` 当前句 + 历史若干行；更早的行进入任务文字稿，不常驻屏幕。
- 同一句的 volatile 更新原地改字（稳定 `utteranceID`），不新开一行。
- final 后 1 秒内，非自信的异语短句会被当作串音丢弃，抑制「嗯 / um」误切。
- 语言对变化时清空当前字幕并重建翻译方向；未完成句丢弃，避免打到错误一侧。

### 3.3 任务与自动开始

- 进入模块不会自动建任务；主操作是「新任务」。
- 新任务记下开始时间、模块、语言对；`autoStartListening` 默认开启，新任务后自动开始听，可在设置关闭。
- 「结束任务」停听写、归档文字稿、写入历史；空稿任务自动删除，不进历史。
- 切模块或进后台只暂停听写，任务仍为进行中；下次进入可继续或结束。
- 杀进程后，未结束任务出现在首页「未完成的任务」，可点回模块继续。

### 3.4 设置

面对面设置卡（`SettingsSheet`）包含：模式切换、我看的语言、对方语言、字号三档、自动开始开关、清屏、总结、重新下载模型、完成。

## 4. 同声传译（Interpretation）

### 4.1 场景与布局

一个人听讲座/会议/导游，手机朝向自己。单栏正字：

- 当前译文最大；历史译文在上方可滚动；原文默认一行小字，可关闭。
- 顶部方向条：`他说 [语言] ⇅ 我听 [语言]`，可点徽章换语言、点箭头对调方向。
- 中央仍是开始/暂停；底部是「读出译文」开关。

### 4.2 方向与识别

- 方向由用户选定：只识别「他说」的语言，只翻译到「我听」的语言。
- 识别结果若不属于源语言，直接丢弃；不因旁路语言改方向。
- 换方向/换语言：停听、清当前 live、保留历史、分析方向重新检查；不自动恢复听，需用户再点开始。
- 进入模块不会自动开始听；新任务后也停在「轻点开始」，避免现场突然出声被录。

### 4.3 字幕与朗读

- 字幕沿用同一套翻译节流：volatile 尽快上屏，final 覆盖。
- 历史字幕内存上限 50 条（`InterpretationLayout.historyLimit`），超出丢弃最早行。
- 「读出译文」默认关闭；只有检测到耳机/听筒等非外放路由才允许打开，否则提示需要耳机并关闭开关。
- 朗读只读已经切出的从句：settled 全段可读；volatile 必须出现终止标点且长度达标才读。
- 朗读队列最多 10 条；超限先丢最短的确认语，再丢最旧任务；暂停立即停止朗读并清空队列。
- 语速固定为系统默认的 1.28 倍（上限钳制），暂无音色/语速设置。

### 4.4 设置

同传设置卡（`InterpretationSettingsSheet`）包含：他说/我听、显示原文、字号、读出译文、清屏、总结、重新下载模型。

## 5. 会议记录（Meeting）

### 5.1 场景与布局

一个人记一场会。单栏正字，完整文字稿按句追加；当前句用较大字号，历史可滚动跟随。

- 不翻译、不朗读、不保存音频；会后可在记录详情里把非界面语言的行译成「我看的语言」。
- 只选一种记录语言，或开启「多语言识别」。
- 多语言识别取 `[我看的语言, 我看的语言.defaultPeer]` 两路；每行标注实际识别语种。
- 单任务文字稿上限 20,000 字符（`MeetingLayout.transcriptCharacterLimit`）；达到上限自动停止并标记 `isLengthLimited`，需结束并新开任务。
- 结束任务时若 subtitle 为空，用首句前 16 字生成副标题。

### 5.2 设置

会议设置卡（`MeetingSettingsSheet`）包含：记录语言、多语言识别、字号、清屏、总结、重新下载模型。

## 6. 任务、历史与会后处理

### 6.1 任务生命周期

```
无任务 ──新任务──► 进行中 ──结束任务──► 已结束（历史）
                    │  ▲
                 暂停听写（任务仍在）
```

| 动作 | 行为 |
| --- | --- |
| 新任务 | 若已有进行中任务，先结束并保存；清空现场字幕；记录模块、语种、开始时间 |
| 开始/暂停 | 只控制麦克风；不结束任务 |
| 结束任务 | 停听写、落盘、标记 ended；空稿自动删除 |
| 切模块/进后台 | 停听写，任务仍进行中 |
| 杀进程 | 下次启动列出未结束任务；可继续或结束 |

标题自动生成，例如 `11月2日 面对面 · 中文 ↔ English`、`11月2日 同声传译 · English → 中文`、`11月2日 会议 · 中文`。

### 6.2 历史

- 历史只显示**已结束**任务，按开始时间倒序，可按模块筛选。
- 列表行显示模块、标题、时长、语种、日期；左滑删除（系统确认）。
- 详情页只读回看全文；可总结、导出分享、删除。
- 会议记录详情支持「译成我看的语言」：逐条调用单向翻译，只回填译文，不改变原文。

### 6.3 未完成任务的恢复

- 首页顶部显示未结束任务，点按直达对应模块。
- 恢复任务会重建文字稿和字幕，但**不恢复任务开始时的语言对**；继续录制使用当前偏好语言。这是已知 P2 问题，见 [`04-roadmap.md`](04-roadmap.md)。

## 7. 总结与导出

### 7.1 总结

总结挂在一条有文字稿的任务上，手动触发：

| 设备状态 | 行为 |
| --- | --- |
| Apple 智能可用 | `FoundationModelsSummarizer` 生成摘要，标注「由 Apple 智能生成」 |
| 支持但未开启 | 说明去系统设置开启；仍可导出 |
| 设备不支持（如 iPhone 13） | 直接说明本机不支持 Apple 智能；仍可导出 |
| 模型未就绪/其他 | 说明暂不可用；仍可导出 |

Apple 智能不可用或生成失败时，自动回退到本地 `digest`：按「你 / 对方」分组拼接原文/译文，**不冒充 AI 摘要**。

### 7.2 导出

- 导出 UTF-8 纯文本到 Caches，文件名 `Duiyi-<feature>-yyyyMMdd-HHmm.txt`。
- 内容：标题、时间范围、方向、文字稿、可选摘要；会议记录每行带语种徽标。
- 使用系统 `ShareLink`，不深链第三方 App、不内嵌 SDK。
- 当前实现每次导出前删除全部 `Duiyi-*.txt`，存在分享竞态，见 [`04-roadmap.md`](04-roadmap.md) P1-2。

## 8. 首次使用与设置

### 8.1 引导

`OnboardingViewModel` 四步：

1. **欢迎**：产品承诺与场景示意。
2. **语言**：选「我看的语言」，对侧自动推导；可跳过使用系统语言。
3. **权限**：麦克风 + 语音识别；拒绝时给「去设置」入口。
4. **模型**：下载语音模型；翻译模型由 `TranslationPrepareHost` 预下载。

翻译预下载成功后引导自动完成并进入首页；失败则停留在模型步骤，可重试。引导进度写入 `PreferencesStore.onboardingStep`，重开 App 可续。

### 8.2 设置入口

| 入口 | 内容 |
| --- | --- |
| 首页齿轮（`HomeSettingsSheet`） | 我看的语言、字号、重新下载模型、打开系统设置 |
| 模块设置卡 | 模块语言/方向、字号、模块开关、清屏、总结、重下模型 |
| 系统设置 | 麦克风/语音识别授权、Apple 智能开关 |

字号三档：标准 / 更大 / 最大；`CaptionTypography` 再叠加系统动态字体，但有上限防止倒字侧溢出。

## 9. 视觉与无障碍

- 深色画布 `#12141A`，暖白正文 `#F4EFE6`，主操作金色 `#E8B86D`；语言徽章各有颜色。
- 系统字体（SF / PingFang），不嵌入第三方字体；最多同时展示当前句 + 上一句。
- 面对面：对方侧旋转 180°，`accessibilityHidden`；VoiceOver 只读用户侧。
- 其他模块：主界面全部进入无障碍树，按钮/卡片有 label 与 hint。
- 降低动态：新句淡入 + 4 pt 上移 180 ms；volatile 只改字；跟随 `AccessibilityReduceMotion`。
- 所有可点区域不小于 44 pt；面对面中央按钮热区 88 pt。

## 10. 明确不做

- 不做账号、云同步、iCloud、自建后端。
- 不保存音频、不做回放、不做说话人分离/声纹。
- 不做外放朗读、不做会议扩音、不做后台持续听写。
- 不在会议记录里做实时同传朗读。
- 不做横屏、iPad、Mac Catalyst、Apple Watch。
- 不以「先选当前说话人」作为面对面/同传的操作前提。

## 11. 验收场景

1. 两人隔桌，各自只懂一种语言，不看说明书即可完成：选语言 → 授权 → 等模型 → 说话 → 在各自一侧读到译文。
2. 一个人听英文演讲，选 English → 中文，轻点开始后看到中文字幕；戴耳机后可听到从句朗读，字幕继续前进。
3. 一场会议结束后，历史里有完整文字稿；iPhone 13 上明确提示不支持 Apple 智能，但可导出文本分享。
4. 任意模块中途切后台/锁屏，任务不丢；回到 App 可继续或结束。
